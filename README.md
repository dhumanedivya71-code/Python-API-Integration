# Python API Integration

This project demonstrates API integration using Python and the Requests library.

## Task 2 - API Integration

The application fetches weather information for a city using an online weather API.

## Features

- Takes city name as input
- Sends an API request using Requests
- Parses JSON response
- Displays weather information
- Shows temperature
- Shows humidity
- Shows weather condition

## Technologies Used

- Python
- Requests
- REST API
- JSON
